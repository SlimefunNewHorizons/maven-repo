Dependencias Drake listas para todos los plugins.

Este repositorio publica los artefactos Maven compartidos del ecosistema Drake/Slimefun, para que los plugins separados de la organizacion compilen sin reactor local, sin jars instalados a mano y sin depender de la cache de un PC.

Flujo recomendado

  1. 1
    Publicar aqui cualquier dependencia interna que un plugin separado necesite.
  2. 2
    Agregar el bloque de repositorio Maven al `pom.xml` del plugin.
  3. 3
    Declarar la dependencia con `scope` correcto: normalmente `provided` para API de servidor y `compile` para librerias sombreadas.
  4. 4
    Validar con un repo Maven temporal limpio antes de pasarle el repo a otro dev.
$tempRepo = Join-Path $env:TEMP ('drake-m2-clean-' + [Guid]::NewGuid().ToString('N'))
New-Item -ItemType Directory -Path $tempRepo | Out-Null
mvn "-Dmaven.repo.local=$tempRepo" -U -DskipTests package

Tambien para Gradle

No necesitamos un segundo repositorio: Gradle consume este mismo Maven repo. Los plugins con `build.gradle` o `build.gradle.kts` deben apuntar a esta URL y declarar las dependencias Drake con `compileOnly` o `implementation` segun corresponda.

Ver guia Gradle Ver publicacion 
repositories {
    maven {
        name = "drakescraftLabs"
        url = uri("https://maven.drakescraft.cl/")
        mavenContent {
            includeGroup("com.github.drakescraft_labs")
        }
    }
}
